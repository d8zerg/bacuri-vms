# Справочник ошибок

[English version](../errors.md)

При ошибке HTTP поле `code` ответа Problem содержит код из каталога. Значение `request_id` совпадает с заголовком `X-Request-Id`. Службы передают причину сбоя gRPC в сообщении статуса. Источники и задания установки карт возвращают причину в поле `error`. Веб-клиент показывает сообщение на выбранном языке.

## Запрос

| Код | Статус HTTP или источник | Действие | Кому | Значение |
| --- | --- | --- | --- | --- |
| `invalid_request` | 400 | Изменить запрос | Администратор | Запрос не соответствует ожиданиям сервера. Проверьте введённые значения. |
| `payload_too_large` | 413 | Изменить запрос | Служба | Тело запроса превышает допустимый размер. |
| `headers_too_large` | 431 | Изменить запрос | Служба | Заголовки запроса превышают допустимый размер. |
| `expectation_failed` | 417 | Изменить запрос | Служба | Сервер не поддерживает значение заголовка Expect. |
| `method_not_allowed` | 405 | Изменить запрос | Служба | Сервер не поддерживает это действие для объекта. |
| `precondition_required` | 428 | Изменить запрос | Служба | Изменение требует прочитанной версии объекта. Обновите данные. |
| `invalid_georeference` | 400 | Изменить запрос | Администратор | Опорные точки не задают положение плана на карте. |
| `camera_selection_expired` | 400 | Выполнить названный шаг | Администратор | Повторите обнаружение и выбор профилей. |
| `invalid_catalog` | состояние карты | Изменить запрос | Администратор | В каталоге карт некорректные данные регионов. |
| `invalid_package` | состояние карты | Изменить запрос | Администратор | Выберите корректный пакет карт в формате ZIP или MBTiles. |
