# План поддержки Windows и macOS в настольном приложении Bacuri VMS

[English version](../devplan-desktop-platforms.md)

Текущий выпуск настольного клиента предназначен для Linux. Этот план охватывает перенос того же клиента на Windows и macOS. Для каждой ОС предусмотрены свой стенд, пакет и результаты приёмки. Выпуск для Linux принимается независимо. Общие сценарии клиента и критерии их приёмки определены в [плане клиента для Linux](../devplan-desktop.md).

| Область | Windows | macOS |
| --- | --- | --- |
| Видео и карта | Проверить аппаратное декодирование D3D11, видеоприёмник GStreamer для D3D11 и передачу общих текстур D3D11 в Qt Quick | Проверить декодирование VideoToolbox, передачу кадров через IOSurface и вывод через Metal в Qt Quick |
| Клавиатура | Вызов командной строки по Ctrl+K | Вызов командной строки по Cmd+K |
| Автономная поставка | Подписанный установщик MSI | Подписанное приложение в DMG |

Для каждой платформы выполнить следующие шаги.

1. **Подготовить стенд и сборку.** Зафиксировать версию ОС, архитектуру процессора, GPU и драйвер, мониторы и масштаб интерфейса, пульт и ключ FIDO2. Настроить передачу заданий сборки с SDK и подписи из конвейера Docker Compose на Linux исполнителю для целевой ОС и сбор полученных артефактов. Для сравнения с Linux использовать те же профили камер, эталонные записи с номерами кадров и сборку сервера.
2. **Проверить вывод видео, карту и ввод.** Открыть эфир и архив H.264 и H.265 рядом с картой. На предложенном для ОС пути вывода измерить число копирований кадра, точность перемотки и задержку ввода под нагрузкой. Проверить программный режим, потерю графического устройства и перенос окна между экранами с разным масштабом. Зафиксировать путь вывода и измеренные пределы для этой ОС. [Замеры и решение для Linux](adr/022-desktop-video-path.md)
3. **Проверить вход и работу с устройствами поста.** Проверить вход через системный браузер, возврат в исходный экземпляр приложения, доверие сертификату, WebAuthn с физическим ключом и корпоративный вход через Keycloak. При отказе провайдера проверить локальный вход администратора. Проверить системные сочетания клавиш, доступность интерфейса, физический пульт и оба языка интерфейса.
4. **Собрать пакет и принять выпуск для ОС.** На чистой машине без внешней сети проверить установку, обновление, откат, проверку подписи и просмотр экспорта. При доступной локальной площадке до входа открыть её публичный портал помощи в системном браузере на языке и в теме клиента. Отключить площадку и проверить сообщение о повторном открытии после восстановления связи. На установленном пакете пройти общие сценарии паритета, проверки нагрузки и отказов, задания администратора и оператора. Для каждой обязательной конфигурации сохранить хеш пакета, версии клиента и сервера, состав оборудования и результаты. Принять каждую платформу по результатам её прогонов. [Общие сценарии паритета](../../desktop/parity.yaml)
