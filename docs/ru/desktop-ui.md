# Экраны настольного клиента

Макеты рабочего места оператора в настольном клиенте. Экраны используют [общие цветовые токены](../../design/bacuri/tokens.css) в тёмной теме и показывают русский интерфейс. Каждый файл - исходник Design Component для дизайн-холста: HTML-страница с разметкой `<x-dc>` и классом `DCLogic`. Локальный [support.js](../desktop-ui/support.js) отображает файлы без сети: откройте [index.html](../desktop-ui/index.html) в браузере. Работают переходы между экранами и командная строка, шрифты берутся из дизайн-комплекта. Видеокадры нарисованы условными сценами. [English version](../desktop-ui.md)

| Экран | Содержание | Исходник |
| --- | --- | --- |
| Стена мониторинга | Камеры с разным соотношением сторон без обрезки, тревожный слот без сдвига остальных ячеек, лента событий, общая шкала эфира с полосой активности, состояния «нет связи» и «субпоток», маска | [main.dc.html](../desktop-ui/main.dc.html) |
| Камера в фокусе | PTZ перетаскиванием в кадре, зум на область рамкой с Shift, положение поворота, наклона и зума, переходы к соседним камерам у краёв кадра, лента камер раскладки в постоянном порядке, предустановки на клавишах 1-6 и диагностика потока | [focus.dc.html](../desktop-ui/focus.dc.html) |
| Синхронный архив | Четыре камеры на одном моменте UTC, отстающая камера и пропуск записи, дорожки камер на шкале от суток до кадров с активностью, тревогами, закладками и защищённым интервалом, обзор суток, кэш опорных кадров и материалы дела | [archive.dc.html](../desktop-ui/archive.dc.html) |
| Обработка тревоги | Повтор момента тревоги с -10 с рядом с эфиром той же камеры, соседние камеры по плану на том же моменте, этапы обработки, действия на клавишах и журнал тревоги | [alarm.dc.html](../desktop-ui/alarm.dc.html) |
| Командная строка | Поиск по Ctrl+K среди камер, раскладок, тревог и действий в пределах прав, время в запросе открывает архив, исправление раскладки клавиатуры, стрелки и Enter | [command.dc.html](../desktop-ui/command.dc.html) |
| План | Секторы обзора, сектор камеры с тревогой, путь по переходам между камерами, предпросмотр эфира при наведении и масштаб от региона до этажа | [map.dc.html](../desktop-ui/map.dc.html) |
| Анатомия ячейки | Элементы ячейки, восемь состояний, роли цветов и радиальное меню с росчерками | [anatomy.dc.html](../desktop-ui/anatomy.dc.html) |
| Пост из трёх мониторов | Роли экранов, программируемая клавишная панель с подписями под выбранную камеру, джойстик и правила поста | [workstation.dc.html](../desktop-ui/workstation.dc.html) |

Общие правила экранов: видео показывается целиком и в исходном цвете без эффектов поверх кадра, позиции ячеек меняются только действием оператора, цвет обозначает только состояния и дублируется формой или подписью, каждое частое действие доступно с клавиатуры, из командной строки, радиального меню и пульта.
