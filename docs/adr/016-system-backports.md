# ADR-016. Сопровождение системных пакетов

**Статус** - Принято.

**Контекст.** Фиксированный снимок Debian 13 обеспечивает повторяемую сборку. Между публикацией исправления поставщиком и его включением в стабильный дистрибутив может оставаться критическое совпадение. Для шага 5.3 нужны проверяемое устранение проблемы, сохранение ABI и возможность автономно повторить решение по конкретному комплекту.

**Варианты.** Переход на другую ветку дистрибутива требует повторной квалификации ABI всех служб. Временное исключение требует доказанной компенсирующей меры. Перенос опубликованного исправления в исходный пакет Debian позволяет сохранить набор интерфейсов и отдельно проверить обновление.

**Решение.** Команда платформы сопровождает локальную ревизию только для используемых пакетов, которым требуется исправление. Бинарные пакеты собираются из точно заданной версии исходников в подписанном архиве Debian. Изменения берутся из выпуска поставщика с проверкой SHA-256. Сборка проверяет прямое и обратное наложение исправления и сохраняет состав зависимостей сборки. При наличии исправленного пакета в той же стабильной ветке устанавливается пакет поставщика с проверкой подписи. Для статических Go-утилит закрепляются исходники, модули и образ компилятора. В разработческом SDK WebRTC достаточно штатных заголовков, метаданных pkg-config и ссылки редактора связей из пакета той же версии, что и библиотека исполнения.

**Основания.** Установка через dpkg сохраняет владельца файлов, версию и штатные механизмы учёта. Для каждого образа автоматика сверяет версии и SHA-256 установленных файлов с результатом сборки. Отдельное сканирование исходной версии Debian сохраняет в отчёте все применимые уведомления. Статус исправленного уведомления привязан к пакету, локальной версии, конкретному патчу и проверенным байтам. Для уведомления об отсутствующей функции нужны проверка состава установленного пакета и проверка среды исполнения. При расхождении проверка завершается ошибкой.

**Последствия и пересмотр.** Команда платформы отвечает за получение новых бюллетеней, проверку совместимости и перенос локального исправления при каждом обновлении исходников. Пакеты и инструменты доступны для выгрузки с материалами сборки. При появлении исправленного пакета в закреплённой ветке перейти на него, убрать локальное правило и повторить сканирование исходного состава и полную регрессию. Каждый новый CVE оценивается отдельно. В 8.1 состав системных пакетов входит в поставку и SBOM, в 12.1 доказательства сверяются с хешем подписанного комплекта.
