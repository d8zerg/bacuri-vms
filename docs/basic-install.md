# Автономная установка Bacuri VMS Basic

Комплект рассчитан на Debian 13 amd64 с systemd, APT и gpgv. Basic поставляется бесплатно для одной локальной площадки. На код проекта распространяются условия MIT из файла LICENSE. Компоненты Debian и веб-клиента сохраняют свои лицензии. Имена и версии поставленных пакетов, медиаплагинов, библиотек и ресурсов клиента перечислены в sbom.json. Версии инструментов сборки поставщик сохраняет в build-tools.json отдельно от компонентов узла.

## Подготовка

Подготовьте локальное DNS-имя площадки, корректное время и сертификат TLS с этим DNS-именем в SAN. Браузер оператора должен доверять центру сертификации. Порт HTTPS - 8443. Смонтируйте выделенный том ext4 в `/srv/bacuri-archive` и закрепите его по UUID в `/etc/fstab`. Установщик проверяет точку монтирования. Форматирование и выбор диска выполняются до установки.

Получите двоичный публичный ключ подписи по доверенному каналу и сверьте его отпечаток с данными поставщика. Перенесите комплект на узел на носителе только для чтения. Переменная `keyring` указывает на доверенный файл ключей, `kit` - на каталог комплекта.

```sh
gpgv --keyring "$keyring" "$kit/bacuri-install.sig" "$kit/bacuri-install" &&
    sudo "$kit/bacuri-install" "$keyring" "$kit"
```

Установщик проверяет подписанный перечень SHA-256 в локальной копии, затем передаёт APT подписанный репозиторий с зависимостями. На чистом узле для установки и работы достаточно локальной сети площадки.

## Начальная настройка

Выполните в локальной консоли следующую команду. В стандартный ввод передайте одну строку пароля первого администратора. В примере пароль считывается без отображения. Укажите сеть камер в формате CIDR.

```bash
read -rs -p 'Пароль администратора: ' password
printf '%s\n' "$password" | sudo /usr/sbin/bacuri-basic setup "$dns_name" "$admin" "$certificate_chain" "$private_key" "$camera_cidrs"
unset password
```

Сохраните одноразовый код из вывода консоли. Он действует десять минут. Откройте адрес площадки в браузере, введите имя и пароль, затем код первичной привязки. Подтвердите регистрацию ключа WebAuthn и вход тем же ключом с проверкой пользователя. При последующих входах администратор вводит пароль и подтверждает запрос ключом. До привязки новый код можно получить командой `sudo bacuri-basic admin enroll-admin "$admin"`.

```bash
systemctl is-active bacuri-core bacuri-recorder bacuri-media
read -rs -p 'Пароль оператора: ' password
printf '%s\n' "$password" | sudo bacuri-basic admin create-user "$operator" operator
unset password
sudo bacuri-basic admin grant-point "$operator" "$point"
sudo bacuri-basic admin revoke-point "$operator" "$point"
```

Команда создания пользователя принимает пароль из стандартного ввода. Идентификатор точки берут из реестра после подключения камеры. Параметры служб и отдельные ключи ядра и рекордера размещены в `/etc/bacuri-vms`. Ключ подписи установочного комплекта остаётся у поставщика.

## Обслуживание установленного узла

Полная резервная копия включает конфигурацию, историю, каталог, TLS и ключи площадки. Используйте её при обновлении, откате и замене системного диска. [Команды обслуживания и восстановления](basic-maintenance.md)

## Сохранение установленной конфигурации

Сохраните защищённую копию `/etc/bacuri-vms` отдельно от архива. Команда `sudo bacuri-basic admin backup-config` выводит зашифрованный снимок в стандартный вывод. Записывайте его в новый файл на независимом носителе с правами `0600` и публикуйте копию только после успешного завершения команды. Для восстановления конфигурации на той же площадке нужны исходные идентификаторы, ключ ядра и чистая либо тождественная БД. При остановленных службах примените `sudo bacuri-basic admin migrate`, затем `sudo bacuri-basic admin restore-config < "$backup"`. Состояние архива после загрузки снимка проверяется командой `sudo bacuri-basic admin recovery-status`. Для возврата видео требуется отдельная сверка сохранившегося архивного тома.
